## Why

- Add a parent-version-scoped override for `ajv@8.17.1>fast-uri` to exactly 3.1.7 and regenerate the lockfile, subject to current advisory and registry verification before implementation.
- Verify the actual Ajv resolver, reproducible installation, module conformance, and unchanged generated contracts and browser assets.
- Retain existing security policies, required checks, and public behavior. No product-boundary additions or removals.
- Record candidate-bound remediation evidence without suppressing findings or claiming an unperformed runtime exploit assessment.
